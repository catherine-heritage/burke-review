# Round 6 — Colour palettes

Imported from the published Burke Colour Palettes Site (version 1), using the
approved Round 4 boards. Open `/burke-review/round-6/` on GitHub Pages or serve
the repository locally. No build step is required; rendering libraries and fonts
are bundled. Earlier rounds are not replaced.

Prepared palettes can be hidden and restored. Colour edits and locks, generation,
favourites, existing brochure previews and competitor colours are preserved.
Current settings and favourites use browser local storage (`burkePaletteExplorer.v2`).
Use favourite Export/Import to move palettes from the original Site.

Competitor data is the supplied research snapshot; the Mango + Plum reference
records the separate orange/purple family-pair concern. Shade scores do not
establish overall brand resemblance.
